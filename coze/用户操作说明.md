## 你不需要再做 Coze 页面操作

不需要重复创建知识库或表格，不需要重新导入状态数据，也不需要再次手工运行验收用例。报告所需的 Coze 截图已保存在 `screenshots/`，截图索引见 `截图清单.md`。

Coze 平台没有向本项目界面提供逐轮完整 workflow 参数、source ID、稳定 run ID、账号余额/实际账单或 embedding 单价；这些位置已经标记为无法观测。不同路线的 UI 计时口径不一致，不据此排整体速度名次。
