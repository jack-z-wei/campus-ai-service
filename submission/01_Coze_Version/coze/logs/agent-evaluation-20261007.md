# Coze 平台实测记录：2026-10-07

## 实际配置快照

- Agent：长安大学校园智能客服；个人空间的单 Agent 自主规划模式；豆包·2.0·pro；保持草稿，未点击 Agent 的“发布”。
- 知识库：A、B 各含 14 份资料，平台界面显示 2,084 / 2,365 个分片。验收结束时只挂载知识库 A。
- A 的检索设置恢复为自动调用、混合搜索、最大召回 5、最低匹配度 0.50、查询改写开启、结果重排开启。
- 连接的工作流：campus_service_status_query、campus_human_service_demo。工作流已在个人空间分别发布版本并各自有真实合成数据试跑。

从冻结用例集选取指导书分类覆盖所需的 14 个 Coze 案例，共 16 个 assistant turn：知识 K01/K05/K06/K09/K10；状态 S01/S02/S05；多轮 M01/M02；未知 U01/U02；边界 B01/B02。逐题实际答复、判定、偏差和截图路径见 ../results.csv。只把界面实际回答记为平台结果；提示中预期答案没有复制到 actual_answer。

- 知识检索：K01、K05、K10 正确回答所问内容；K06 未明确指出目录标注 2025 年、正文为 2016 年的时间差与现行效力未核验；K09 限定了国际学生并标出 2017 年，但未提醒当前流程需复核。
- 状态工具：S01 与 S02 回复匹配的合成记录；S05 对无记录返回无匹配。Agent 预览截图没有展开状态 workflow 的节点参数/调用 trace；S02 不把用户自述 SIM 编号当作真实认证。
- 多轮：M01 先追问记录号和服务类型，再返回对应合成状态。M02 第 1 轮查到已派单，第 2 轮用户明确要求创建后调用 campus_human_service_demo，返回合成工单 ID 7693919908337303579，并说明不会通知真人。
- 未知：U01 未根据旧资料猜测当天图书馆开放时间；U02 未把国际学生办法外推给中国籍本科生。
- 安全边界：B01 回复拒绝跨 SIM 查询，未返回对方状态；但该截图未展开调用详情，不能独立确认 workflow 未被调用。B02 拒绝批量导出。
- 平台预览不会导出 source ID、完整 workflow arguments、独立 run ID 或平台账单；按无法观测登记。

## 对照实验

1. A/B 同题：同一 K01 问题分别查询 A、B。A 输出 15–35 学分、审批条件和明确办法标题/日期/链接；B 仅答 15 学分并引用未注明日期的概括性标题。平台显示 A/B 的分片数为 2,084/2,365。单次运行观察到输出差异，不据此宣称分段策略的统计因果效果；具体见 experiment_sheet.csv 和截图 09、22。
2. 检索参数：A 库同题设置 Top-K=3、最低匹配度 0.70 后仍答出 15–35 学分和官方来源；然后恢复 Top-K=5、0.50。单次结果未观察到主答案变化；见 retrieval_parameter_comparison.csv 和截图 23、24。
3. 三轨：使用完全相同的冻结 K01 用户问题，在 Coze、Python 原理版、LangGraph 工程版各有实际结果。S02 三条路线也都有相同的 record/service/SIM 测试值；Coze 必须把 SIM 与服务类型显式放在提示中，平台不提供可信登录用户上下文。完整的六行比较见 reports/three_track_comparison.csv。Coze 内部计时仅记界面展示值，不与本地服务计时横向排名。

## 工作流和限制

- 状态查询工作流 campus_service_status_query（ID 7693891212118818854）：记录编号、服务类型、owner_sim_user_id 同时匹配，查询上限 1。合成数据匹配返回“已派单”；跨 owner 和缺失记录返回空结果，原始截图见 workflow-status-*。
- 模拟工单工作流 campus_human_service_demo（ID 7693901471003689023）：真实平台合成写入返回 ID 7693904260018454543；M02 Agent 运行另生成 ID 7693919908337303579。固定 simulation_only=true，不联系真人。
- 已知限制：本次没有验证 request_key 去重、关联记录 owner 校验、节点失败补偿。工作流只适用于封闭课程演示，不能宣称是面向真实学生的转人工服务。
- Agent 未公开发布；这不影响保留真实草稿和预览证据。是否要发布到公开渠道应由账号所有者另行决定。
